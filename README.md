## INSTALLATION GUIDE

### Supported Operating Systems & System Prerequisites

- **Operating System:** Ubuntu Linux (tested on Ubuntu 20.04 LTS and 22.04 LTS).
- **Privileges:** `sudo` / root access (required to install system packages, capture packets, and run Argus).
- **Hardware Requirements:**
  - **CPU:** 2+ cores recommended for concurrent network capture and flow processing.
  - **RAM:** 4 GB minimum (8 GB+ recommended for handling large PCAPs and datasets).
  - **Disk Space:** Sufficient local storage for `.pcap`, `.hera`, and generated `.csv` files.

### Tested Software Versions

| Component | Tested Version |
| :--- | :--- |
| **OS** | Ubuntu 22.04 LTS / 20.04 LTS (x86_64) |
| **Python** | Python 3.11.x |
| **Argus Server** | `argus-server` 3.0.8.2+ |
| **Argus Client** | `argus-client` 3.0.8.2+ (`ra`, `rasplit`, `racount`) |
| **Wireshark / TShark** | `tshark` 3.6.x / 4.x |
| **Build Tools** | `gcc`, `make`, `build-essential` |

### Quick Start (Automated Installation)

Clone the repository and run:

```bash
make run
make clean
```

## USER GUIDE

### HERA GUI

Just run jupyter notebook and follow the workflow of the notebook.

### HERA CLI

For HERA CLI you have a set of commands to help you skip some steps. 

For hera.py:

```bash
python hera.py
python hera.py --pause-after-workspace
python hera.py --step [workspace|capturing|flow|dataset|labelling]
python hera.py --from-step [workspace|capturing|flow|dataset|labelling]
```

### Ground Truth

The ground truth file should have the following fields: StartTime,LastTime,SrcAddr,Sport,DstAddr,Dport,Proto,BinaryLabel,CategoryLabel,SubCategoryLabel
